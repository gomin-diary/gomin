# 공용 네비게이션 자산

홈·가이드·컬렉션 SVG는 Figma `Mobile Bottom Navigation` 원본의 32×32 정의를 재사용한다. `*-active.svg`는 활성 상태, 나머지는 비활성 상태이다. 고유 크기를 유지해 장식용 `alt=""` 이미지로 사용하고 링크 이름은 인접한 텍스트로 제공한다.

[화면과 자산 매핑](../../../../docs/frontend/shared-ui.md)

프로필 캐릭터 PNG와 프로필·설정·이동·로그아웃 SVG는 Figma 데스크톱 앱에서 원본 레이어를 내보냈다. `profile-active.svg`는 설정 화면의 활성 프로필 탭에 사용한다.
