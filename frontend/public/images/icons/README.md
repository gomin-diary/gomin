# 고민일기 SVG 아이콘

- `sprout.svg`: 새싹. 배경 투명, 32×32 viewBox. Figma `Icon / Sprout`과 동일한 벡터.
- `leaf.svg`: 상단 브랜드용 잎. 배경 투명, 24×24 viewBox.

텍스트 옆에서는 Figma Auto layout에 아이콘 인스턴스와 텍스트를 함께 넣고 가운데 정렬하세요. SVG는 폰트 문자가 아니라 크기를 조절할 수 있는 벡터입니다.

웹 예시: `<img src="/images/icons/sprout.svg" width="20" height="20" alt="" style="vertical-align: middle" />`.
의미를 전달하는 아이콘은 적절한 대체 텍스트를 지정하고, 장식용은 빈 alt를 사용하세요.
