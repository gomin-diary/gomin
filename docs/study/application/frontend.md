# 프론트엔드와 Next.js

로그인 화면에는 입력란, 버튼, 안내 문구가 있다. 값을 입력하면 화면이 바뀌고 요청이 실패하면 오류를 보여준다. 프론트엔드는 이런 화면 구성과 사용자 조작을 다룬다.

## HTML, CSS, JavaScript

HTML은 제목, 문단, 입력란, 버튼 같은 문서의 구조를 표현한다. CSS는 색상, 글꼴, 간격, 화면 배치를 정한다. JavaScript는 클릭에 반응하거나 서버에 요청을 보내는 동작을 담당한다.

예를 들어 로그인 버튼은 HTML로 만들고 CSS로 크기와 색을 정한다. 버튼을 눌렀을 때 입력값을 읽고 API를 호출하는 부분은 JavaScript가 맡는다. 세 기술이 한 화면에서 함께 쓰인다.

TypeScript는 JavaScript에 타입을 표현하는 문법을 더한 언어다. 함수에 어떤 값을 전달하는지, 반환값에 어떤 필드가 있는지 개발 중에 확인하도록 돕는다. 타입 선언만으로 서버에서 받은 데이터가 실행 중에도 올바르다고 보장하지는 않는다.

## React는 화면을 어떻게 나눌까

React는 화면을 컴포넌트로 나눠 만드는 라이브러리다. 컴포넌트는 입력란, 메뉴, 로그인 폼처럼 역할이 있는 화면 조각이다. 작은 컴포넌트를 조합해 페이지를 만든다.

컴포넌트에 전달하는 값을 props라고 부른다. 컴포넌트가 기억하며 변경하는 값은 상태다. “입력한 이름”, “메뉴가 열렸는지”, “요청을 기다리는지” 등이 상태가 될 수 있다. 상태가 바뀌면 React가 그 값에 맞는 화면을 다시 계산한다. 이 과정을 렌더링이라고 한다.

다음은 props를 설명하기 위한 짧은 예시다.

```tsx
function Greeting({ name }: { name: string }) {
  return <p>{name}님, 안녕하세요.</p>;
}
```

HTML처럼 보이는 부분은 JSX라는 문법이다. 예시의 `name`에는 컴포넌트를 사용하는 쪽에서 이름을 전달한다.

## Next.js의 역할

Next.js는 React로 웹 애플리케이션을 만들 때 필요한 라우팅, 렌더링, 빌드 등의 기능을 제공하는 프레임워크다. 라우팅은 `/login` 같은 주소를 어떤 페이지와 연결할지 정하는 일이다. 여러 페이지에 공통으로 쓰는 틀은 레이아웃으로 묶는다.

Next.js App Router는 서버 컴포넌트와 클라이언트 컴포넌트를 함께 사용한다. 서버 컴포넌트는 서버에서 실행한다. 클라이언트 컴포넌트는 상태·이벤트·브라우저 기능이 필요한 부분에 사용한다. 클라이언트 컴포넌트도 첫 화면을 준비하는 과정에서 서버에서 HTML을 만들 수 있다. 이름만 보고 실행 위치를 한 곳으로 단정하지 않는다.

렌더링은 화면에 표시할 결과를 만드는 일이고 빌드는 배포할 파일과 실행 결과물을 준비하는 일이다. 페이지에 따라 빌드할 때 결과를 만들거나 요청이 들어왔을 때 만들 수 있다.

## 우리 프로젝트에서는

`frontend/src/app/`에서 페이지와 레이아웃을 구성하고 `frontend/src/components/`에서 공통 화면 조각을 관리한다. `(service)`는 서비스 페이지를 묶는 경로 그룹이며 괄호 이름 자체는 URL에 나타나지 않는다.

서비스 화면은 Provider에서 인증 상태와 공통 UI 상태를 공유한다. Provider는 하위 컴포넌트가 같은 값을 사용하도록 연결하는 컴포넌트다. 메뉴 같은 UI 상태에는 Zustand를 사용한다.

`/docs`는 서비스의 인증 Provider와 분리한 문서 영역이다. 저장소의 Markdown을 빌드 전에 읽어 문서 데이터를 만들고 페이지를 정적으로 생성한다. 자세한 동작은 [공개 문서 화면](../../frontend/docs-ui.md)에서 확인한다.

API 요청은 공통 함수 `apiFetch`가 Render의 백엔드로 보낸다. 서버의 DB 전용 키를 화면에 전달하지 않는다.

## 자주 헷갈리는 점

화면의 메모리에 저장한 상태는 새로고침하면 사라질 수 있다. 로그인 상태를 화면에서 기억하는 것과 서버가 세션을 검증하는 일도 다르다. 서버는 실제 요청의 인증 정보를 보고 판단한다.

Vercel은 이 Next.js 앱을 배포하는 플랫폼이다. React, Next.js, Vercel은 각각 라이브러리, 프레임워크, 배포 플랫폼이라는 역할을 맡는다.
