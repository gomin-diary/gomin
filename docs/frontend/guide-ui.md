# 가이드 화면

`/guide`는 고민일기 이용 흐름을 소개한다. `frontend/src/app/guide/page.tsx`가 콘텐츠를, `guide.module.css`가 반응형 배치를 관리한다. 기존 `PageShell`과 메뉴, 온글잎 콘콘체를 재사용한다.

## 디자인과 동작

- [PC 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=82-834): 방 배경과 28% 밝은 베일, 제목·모리 소개, 번호가 있는 안내 카드 4개, 털어놓기 버튼.
- [모바일 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=48-72): 크림색 배경, 모리 소개, 그림과 설명을 나란히 둔 세로 카드 4개, 털어놓기 버튼과 공용 하단 메뉴.
- 768px 이상은 카드 4열, 미만은 카드 1열이다. 작은 화면의 문구는 가독성을 위해 최소 글자 크기를 적용하며 필요한 경우 줄바꿈과 세로 스크롤을 허용한다.
- 털어놓기는 `/talk`로 이동한다. 모바일 물음표 링크는 이용 단계로 스크롤한다. 카드 자체에는 클릭 동작이 없다.
- 이미지는 설명과 중복되는 장식이므로 빈 대체 텍스트를 사용한다. 이용 순서는 순서 있는 목록으로 제공한다.

## 이미지 출처

2026-10-02 Figma 앱에서 PC·모바일 완성 화면과 공용 일러스트를 확인했다. MCP 디자인 조회와 다운로드는 Starter 호출 한도로 실패해 앱의 PNG 내보내기를 사용했다.

## 검증

프론트엔드 lint, typecheck, build와 브라우저의 이미지 로딩·비율, 가로 넘침, 메뉴 활성 상태, 털어놓기 이동, 작은 화면 스크롤을 확인한다. 실제 모바일 기기의 안전영역과 Safari 렌더링은 별도 확인 대상이다. 대화·그림 생성·컬렉션 저장 기능은 이 안내 화면의 구현 범위에 포함되지 않는다.

2026-10-02 lint·typecheck·프로덕션 빌드가 통과했다. Chrome에서 2560×1440, 1440×900, 390×844, 320×568, 844×390의 이미지 5개 디코딩·비율, 카드 4개, 가이드 메뉴 활성 상태와 가로 넘침을 확인했다. 모바일에서 끝까지 스크롤하면 버튼이 하단 메뉴 위에 노출되며, 털어놓기의 `/talk` 이동과 물음표의 이용 단계 이동도 통과했다. PC·모바일 렌더링을 원본 화면과 시각적으로 대조했다. 화면 크기를 바꾸는 검증 중 이미지 preload 경고가 있었으며 마지막 조회에서 런타임 오류는 없었다. 기존 다중 잠금 파일에 대한 Next.js 경고는 유지한다.
