# 가이드 화면

`/guide`는 고민일기 이용 흐름을 소개한다. `frontend/src/app/guide/page.tsx`가 콘텐츠를, `guide.module.css`가 반응형 배치를 관리한다. 기존 `PageShell`과 메뉴, 온글잎 콘콘체를 재사용한다.

## 디자인과 동작

- [PC 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=82-834): 방 배경과 밝은 베일, 제목·모리 소개, 번호가 있는 안내 카드 4개, 털어놓기 버튼.
- [모바일 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=48-72): 크림색 배경, 모리 소개, 그림과 설명을 나란히 둔 세로 카드 4개, 털어놓기 버튼과 공용 하단 메뉴.
- PC에서는 카드 4개를 가로로, 모바일에서는 세로로 배치한다. 작은 화면의 문구는 가독성을 위해 최소 글자 크기를 적용하며 필요한 경우 줄바꿈과 세로 스크롤을 허용한다.
- PC 카드 영역은 화면 너비를 넓게 사용한다. 제목·모리·카드·버튼은 하나의 비율로 함께 확대하며, 화면 높이에 맞춰 크기를 제한해 한눈에 보이도록 한다. 전체 구성과 털어놓기 버튼은 가운데 정렬한다.
- 털어놓기는 `/talk`로 이동한다. 모바일 물음표 링크는 이용 단계로 스크롤한다. 카드 자체에는 클릭 동작이 없다.
- 이미지는 설명과 중복되는 장식이므로 빈 대체 텍스트를 사용한다. 이용 순서는 순서 있는 목록으로 제공한다.

## 이미지 출처

공용 일러스트는 Figma의 `Guide / Shared Illustrations · PC & Mobile` (`78:635`)에서 가져온 PNG 자산이다. `frontend/public/images/guide/`에 포함하며 투명도와 비율을 유지한다.

| 파일 | 원본 노드 | 사용 위치 |
| --- | --- | --- |
| `mori-0-4x.png` | `78:636` | 제목 아래 소개 |
| `mori-1-4x.png` | `78:638` | 이야기 안내 |
| `mori-2-4x.png` | `78:640` | 마음 정리 안내 |
| `mori-3-4x.png` | `78:642` | 그림 완성 안내 |
| `mori-4-4x.png` | `78:644` | 컬렉션 안내 |

PC 배경은 기존 `login-desktop` AVIF/WebP를 재사용한다. 모바일에는 사진 배경을 표시하지 않는다.

대화·그림 생성·컬렉션 저장 기능은 이 안내 화면의 구현 범위에 포함되지 않는다.
