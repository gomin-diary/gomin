# 공용 화면과 배경 매핑

## 경로와 메뉴

`frontend/src/lib/shared-pages.ts`가 메뉴 정의와 페이지별 배경을 관리한다. `PageShell`은 장식용 배경, 브랜드, 메뉴, 본문 건너뛰기 링크를 제공한다. `SiteMenu`는 Next.js Link와 현재 URL을 사용하며 활성 링크에 `aria-current="page"`를 설정한다. 하위 경로는 부모 메뉴를 활성화한다.

| 페이지 | 경로 | PC 메뉴 | 모바일 메뉴 |
| --- | --- | --- | --- |
| 홈 | `/` | 상단, 홈 활성 | 본문 가이드·컬렉션·프로필 바로가기, 하단 메뉴 숨김 |
| 가이드 | `/guide` | 상단, 가이드 활성 | 하단, 가이드 활성 |
| 컬렉션(보관함) | `/collection` | 상단, 컬렉션 활성 | 하단, 컬렉션 활성 |
| 로그인 | `/login` | 상단, 활성 항목 없음 | 숨김 |
| 회원가입 | `/signup` | 상단, 활성 항목 없음 | 숨김 |
| 대화 | `/talk` | 숨김 | 숨김 |
| 설정 | `/settings` | 상단, 활성 항목 없음 | 하단, 프로필 활성 |

홈은 [홈 화면](home-ui.md)의 소개·대화 시작 버튼과 모바일 일러스트 바로가기를 제공한다. 컬렉션·대화는 준비 안내 화면을 제공한다. 가이드는 [가이드 화면](guide-ui.md)의 이용 단계와 대화 이동 버튼을 제공한다. 로그인·회원가입은 [인증 화면 디자인](auth-ui.md)의 입력 화면을 제공한다. 대화·컬렉션의 업무 기능은 별도 작업 대상이다. 홈에서 가이드·컬렉션·프로필·대화로, 가이드에서 대화로, 로그인과 회원가입 사이로 이동할 수 있다. 각 준비 화면에는 홈으로 돌아가는 링크가 있다.

[비로그인 접근 정책](../engineering/login-auth.md#비로그인-접근-정책)에 따라 가이드만 공개 서비스 화면으로 제공한다. 로그인·회원가입은 인증 진입을 위해 허용하고, 홈·컬렉션·대화·설정은 로그인 상태를 확인한 뒤 표시한다. 비로그인 상태에서 보호 화면 링크를 선택하거나 URL로 직접 접근하면 로그인으로 이동하며 인증 후 요청 화면으로 복귀한다.

PC에서는 상단 메뉴, 모바일에서는 하단 메뉴를 사용한다. 모바일 하단 메뉴는 기기의 안전영역을 고려한다. 공용 레이아웃은 현재 화면 높이에 맞추고, 헤더와 모바일 하단 메뉴 공간을 제외한 나머지를 본문에 배정한다. 긴 내용은 본문 안에서만 스크롤하며 배경은 화면 크기에 맞춰 잘린다. 홈·가이드·컬렉션·프로필 4개 링크는 같은 너비로 배치한다. Figma 홈 모바일의 일러스트 메뉴는 별도 홈 콘텐츠이고 이 공용 하단 메뉴와 구분한다.

## 로그인 상태별 네비게이션

준비 안내 카드는 본문 가운데 배치하고 제목·문구·이동 링크를 가운데 정렬한다. 공용 제목과 여백에는 화면 높이에 따른 크기 상한을 적용한다.

[Figma 인증 네비게이션](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=221-4690)을 기준으로 구성한다.

- PC 비로그인: 상단 프로필 숨김
- PC 로그인: 캐릭터 선택 시 내 계정·로그아웃 메뉴 표시, 내 계정은 `/settings` 이동
- PC 메뉴: Escape·바깥 클릭·페이지 이동 시 닫기
- 모바일 프로필: 비로그인은 `/login`, 로그인은 `/settings` 이동
- 설정: 로그인 확인 후 내 계정 카드·로그아웃 제공, 비로그인은 로그인 후 설정으로 복귀
- PC 최초 인증 상태 확인 중·최초 조회 실패: 상단 프로필 숨김. 캐시가 있는 재확인 실패 시 기존 프로필 유지
- 모바일 최초 인증 상태 확인 중: 프로필 이동 비활성화, 최초 조회 실패 시 상태 재확인 제공. 캐시가 있는 재확인 실패 시 기존 프로필 이동 유지
- 로그아웃: 현재 세션 제거 후 가이드 이동, 실패 시 현재 화면에서 오류 안내와 재시도 제공

설정은 단색 배경을 사용한다. 인증 상태는 기존 `AuthProvider`를 재사용하며 화면 아래의 별도 세션 버튼은 표시하지 않는다. 계정 정보 수정은 제공하지 않는다.

## 배경 매핑

아래 이미지 이름에는 `/images/backgrounds/` 접두사와 `.avif` 또는 `.webp` 확장자가 붙는다. 모든 배포 자산은 `frontend/public`에 포함되며 로컬 `figma/`에 런타임 의존하지 않는다.

| 페이지 | PC 자산 / Figma 노드 | 모바일 자산 또는 색상 / Figma 노드 |
| --- | --- | --- |
| 홈 | `home-desktop` / `39:48` | `home-mobile` / `23:3` |
| 가이드 | `login-desktop` / `25:2` (`82:835`에서 재사용) | `#fcfaf4` / `48:72` |
| 컬렉션 | `collection-desktop` / `65:114` | `#0b0e0d` / `84:1065` |
| 로그인 | `login-desktop` / `25:2` | `login-mobile` / `23:2` |
| 회원가입 | 로그인과 동일 / `84:1285` | 로그인과 동일 / `84:1362` |
| 대화 | `talk-desktop` / `85:1433` | `talk-mobile` / `85:1434` |

홈 PC는 헤더 아래 영역에 배경을 표시하며 나머지 이미지 배경은 화면 전체를 채운다. `picture`와 media 조건으로 기기에 맞는 파일을 선택하고 AVIF 미지원 시 WebP로 폴백한다. `object-fit: cover`로 원본 비율을 유지하므로 화면 비율에 따라 가장자리 일부는 잘릴 수 있다. 배경은 본문 뒤에 배치하고 포인터와 접근성 트리에서 제외한다. 준비 안내 카드는 밝은 배경으로 텍스트 대비를 확보한다.

모바일 가이드와 컬렉션에는 사진 배경을 추가하지 않는다. 각 원본 화면의 단색 배경을 사용한다. PC 가이드에는 콘텐츠용 밝은 베일을 적용한다. 대화의 조용한 배경 오버레이는 해당 업무 화면 구현에서 적용할 수 있다.

## 자산 출처

배경과 메뉴 자산은 [Figma 디자인](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ)과 [PC 메뉴](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=28-69)를 기준으로 한다. 배경은 원본 컴포넌트에서 가져온 AVIF/WebP 자산을 사용한다.

`/images/navigation/`의 홈·가이드·컬렉션 SVG는 Figma 모바일 메뉴를 만든 로컬 원본의 SVG 정의를 그대로 파일로 재사용한다. 홈·책·컬렉션 아이콘의 활성/비활성 모양과 색상을 유지한다. `/images/icons/leaf.svg`는 기존 브랜드 자산을 재사용한다. 브랜드·메뉴·본문 글꼴은 `frontend/public/fonts/Ongleip-konkon.ttf`를 로컬 제공하는 온글잎 콘콘체를 사용한다.

프로필 캐릭터는 `Auth / Desktop account`의 이미지 레이어 `236:5249`에서 가져온 PNG 자산이다. `profile.svg`, `profile-active.svg`, `settings.svg`, `next.svg`, `logout.svg`, `back.svg`는 Figma 앱에서 각 아이콘 레이어를 SVG로 내보냈으며 런타임에는 로컬 자산만 사용한다.

## Favicon과 공유 메타데이터

루트 레이아웃은 `/images/icons/sprout.svg`를 SVG favicon으로 사용한다. 공통 Open Graph와 Twitter `summary_large_image`에는 기존 서비스 제목·설명과 `/images/og/gomin-diary.png`(1200×630)를 제공한다. 공유 이미지는 프로필 캐릭터 PNG를 참조해 생성한 크림색 배경의 가로형 카드이며 원본 네비게이션 자산은 유지한다. 이미지의 절대 URL 설정은 [프론트엔드 배포 안내](../deployment/README.md#프론트엔드--vercel)를 따른다.

## 검증 기준

코드 검사는 [코딩과 검증 규칙](../engineering/coding-conventions.md)을 따른다.
PC·모바일·가로 화면에서 다음 동작을 확인한다.

- 메뉴 이동, 현재 메뉴 표시, 페이지별 메뉴 노출과 인증 상태별 동작
- 이미지 로딩과 WebP 폴백, 가로 넘침, 콘텐츠와 메뉴 겹침
- 키보드 포커스, 본문 건너뛰기, 긴 콘텐츠 스크롤, 새로고침과 페이지 전환

실제 모바일 기기의 안전영역과 Safari 렌더링은 브라우저의 화면 크기 변경만으로 확인할 수 없으므로 별도로 검증한다.
