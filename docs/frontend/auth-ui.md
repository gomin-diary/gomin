# 인증 화면 디자인

`/login`과 `/signup`은 `AuthPage`를 사용한다. 공용 `PageShell`의 배경·PC 메뉴를 재사용하며, 모바일에서는 헤더를 숨기고 인증 화면 본문에 브랜드를 표시한다. 글꼴은 온글잎 콘콘체를 사용한다.

## Figma 기준

| 화면 | 원본 노드 | 기준 크기 |
| --- | --- | --- |
| PC 로그인 | `65:151` | 2560×1440 |
| 모바일 로그인 | `82:789` | 1440×3120 |
| PC 회원가입 | `84:1283` | 2560×1440 |
| 모바일 회원가입 | `84:1284` | 1440×3120 |

[Figma 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=65-151)은 MCP Starter 조회 한도로 데스크톱 앱에서 네 화면을 확대해 확인했다. 로그인에는 소개 문구, 이메일·비밀번호 필드, 비밀번호 찾기, 로그인 버튼, Apple·Google·네이버 버튼과 회원가입 링크가 있다. 회원가입에는 이름·이메일·이메일 인증 요청·비밀번호·비밀번호 확인·약관 동의·가입 버튼과 로그인 링크가 있다. 인증번호 필드는 인증 요청 후 표시한다.

소셜 아이콘 3개는 `Login / Supporting Components`의 원본 컴포넌트를 SVG로 내보냈다. 입력 아이콘 5개는 기존 `figma/signup/code.js`의 SVG 정의를 재사용한다. 배포 자산은 `frontend/public/images/auth/`에 있으며 실행 시 `figma/`를 참조하지 않는다. 모바일 인증 배경도 현재 Figma `23:2`를 PNG 1×로 내보내 AVIF/WebP로 변환했다. 기존 모바일 자산의 하늘 배경과 구분한다. 반응형 크기와 간격은 `auth-page.module.css`에 정의하고, 작은 화면에서는 입력 영역과 터치 대상의 사용성을 확보한다.

## 입력 동작과 연동 범위

`AuthForm`은 클라이언트 컴포넌트로 입력과 비밀번호 표시 전환, 체크박스, 오류·상태 안내를 관리한다. 상태는 해당 화면에서만 유지하고 전역 스토어나 브라우저 저장소에 저장하지 않는다. 로그인과 회원가입 간 이동은 Next.js Link를 사용한다.

- 이메일·필수 입력·회원가입 비밀번호 최소 8자는 브라우저의 입력 유효성 검사를 사용한다.
- 비밀번호 확인이 다르면 오류를 표시하고 확인 필드로 포커스를 옮긴다.
- 약관 동의 전에는 가입 버튼이 비활성화된다. 현재 동의 선택은 서버에 기록되지 않는다.
- 인증 요청은 이메일을 검사한 뒤 인증번호 입력 영역을 보여준다. 메일 발송이나 인증 완료를 가장하지 않으며, 확인 버튼은 미연동 안내를 표시한다. 실제 인증 타이머는 아직 시작하지 않는다.
- 로그인은 `apiFetch`로 인증 API에 연결한다. 요청 중 중복 제출 방지·오류 안내·성공 후 홈 또는 보호 화면 이동을 제공한다. 가입·소셜 로그인·비밀번호 찾기는 준비 안내를 유지한다.

로그인·현재 사용자·로그아웃 API와 쿠키 처리는 [이메일 로그인과 세션](../engineering/login-auth.md)을 따른다. 가입 구현에서는 이메일 인증 상태, 인증번호 만료, 중복 계정, 약관 문서와 동의 기록을 연결해야 한다.

## 검증

코드 변경 시 `npm --prefix frontend run lint`, `npm --prefix frontend run typecheck`, `npm --prefix frontend run build`를 실행한다. PC·모바일에서 폼 배치, 메뉴 노출, 가로 넘침, 입력 유효성, 비밀번호 전환, 약관 동의, 인증번호 필드 표시, 페이지 이동, 자산 로딩과 키보드 포커스를 확인한다. 인증 API 연동 전 초기 화면 검증에서는 Chrome에서 두 경로 × 6개 화면 크기(2560×1440, 1440×900, 768×1024, 390×844, 320×568, 844×390)의 배치·이미지·메뉴·가로 넘침과 입력 동작을 확인했다. 초기 화면의 입력·비밀번호 표시·약관·인증번호 표시·페이지 이동 과정에서는 쓰기 요청이나 브라우저 런타임 오류가 없었다. 이후 로그인 연동 검증 범위는 [이메일 로그인과 세션](../engineering/login-auth.md)에 기록한다.

이메일 인증·회원가입·메일 발송은 아직 화면에 연결하지 않았다. 실제 iOS/Android 기기의 키보드·안전영역과 Safari 렌더링은 확인하지 않았다. 모바일 입력 글자 크기는 포커스 시 확대를 줄이기 위해 16px 이상으로 유지한다.
