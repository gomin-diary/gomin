# 인증 화면 디자인

`/login`과 `/signup`은 `AuthPage`를 사용한다. 공용 `PageShell`의 배경·PC 메뉴를 재사용하며, 모바일에서는 헤더를 숨기고 인증 화면 본문에 브랜드를 표시한다. 글꼴은 온글잎 콘콘체를 사용한다.

## Figma 기준

| 화면 | 원본 노드 | 기준 크기 |
| --- | --- | --- |
| PC 로그인 | `65:151` | 2560×1440 |
| 모바일 로그인 | `82:789` | 1440×3120 |
| PC 회원가입 | `84:1283` | 2560×1440 |
| 모바일 회원가입 | `84:1284` | 1440×3120 |

[Figma 원본](https://www.figma.com/design/t66NuRwO9mgwGbLTc2allQ?node-id=65-151)은 MCP Starter 조회 한도로 데스크톱 앱에서 네 화면을 확대해 확인했다. 로그인에는 소개 문구, 이메일·비밀번호 필드, 비밀번호 찾기, 로그인 버튼, Apple·Google·네이버 버튼과 회원가입 링크가 있다. 회원가입에는 이름·이메일·이메일 인증 요청·비밀번호·비밀번호 확인·약관 동의·가입 버튼과 로그인 링크가 있다. 인증번호 필드는 인증 요청 후 표시한다.

소셜 아이콘 3개는 `Login / Supporting Components`의 원본 컴포넌트를 SVG로 내보냈다. 입력 아이콘 5개는 기존 `figma/signup/code.js`의 SVG 정의를 재사용한다. 배포 자산은 `frontend/public/images/auth/`에 있으며 실행 시 `figma/`를 참조하지 않는다. 모바일 인증 배경도 현재 Figma `23:2`를 PNG 1×로 내보내 AVIF/WebP로 변환했다. 기존 모바일 자산의 하늘 배경과 구분한다. 반응형 크기와 간격은 `auth-page.module.css`에 정의하고, 작은 화면에서는 입력 영역과 터치 대상의 사용성을 확보한다.

## 공통 화면과 기능 연결

`AuthPage`는 배경·문구·폼 영역을 제공한다. 기능 화면은 `children`으로 입력 폼을 전달한다.
공통 레이아웃을 수정하지 않고 로그인·회원가입의 입력과 제출 동작을 각각 연결할 수 있다.
폼을 전달하지 않으면 기존 `AuthForm` 준비 화면을 표시한다.

입력·비밀번호 표시·검증·오류 안내는 각 폼에서 관리한다. 민감한 입력과 가입 증표는
해당 화면의 메모리에 유지한다. 로그인과 회원가입 간 이동은 Next.js Link를 사용한다.
인증 API 호출은 `apiFetch`로 백엔드를 직접 호출하며 쿠키·세션 동작은
[공통 인증·DB 기반](../engineering/auth-foundation.md)을 따른다.
로그인 폼과 재인증 안내는 `AuthPage`의 `children`으로 전달한다. 로그인 API·세션·검증 범위는
[이메일 로그인과 세션](../engineering/login-auth.md)을 따른다.
`/signup`은 `SignupForm`을 `AuthPage`의 `children`으로 전달한다. 이메일 인증·일회용 증표·
약관 동의·가입 API와 검증 범위는 [회원가입 구현](../engineering/signup.md)을 따른다.
약관과 개인정보 전문은 `/terms`, `/privacy`에서 제공한다.

## 검증

코드 변경 시 `npm --prefix frontend run lint`, `npm --prefix frontend run typecheck`,
`npm --prefix frontend run build`를 실행한다. PC·모바일에서 폼 배치, 메뉴 노출,
가로 넘침, 입력 유효성, 비밀번호 전환, 페이지 이동, 자산과 키보드 포커스를 확인한다.

API 연동 전 준비 화면에서는 Chrome의 두 경로와 6개 화면 크기
(2560×1440, 1440×900, 768×1024, 390×844, 320×568, 844×390)에서
배치·이미지·메뉴·가로 넘침과 입력 동작을 확인했다. 이 기록은 현재 기능의
가입·로그인이나 메일 발송 검증을 대신하지 않는다. 실제 iOS/Android 기기와
Safari 렌더링은 확인하지 않았다. 모바일 입력 글자 크기는 16px 이상을 유지한다.
